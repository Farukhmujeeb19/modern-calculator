# modern-calculator
A stylish and responsive Modern Calculator Web App built using HTML, CSS, and JavaScript. This project demonstrates DOM manipulation, event handling, CSS transitions, and modern UI design.
Features

➕ Addition
➖ Subtraction
✖ Multiplication
➗ Division
🧮 Remainder (%)
⚠ Divide-by-zero protection
🎨 Modern glassmorphism design
✨ Smooth hover and click animations
📱 Responsive layout.
